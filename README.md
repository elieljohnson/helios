# Helios

Home energy intelligence — unifying solar (Enphase), battery (Tesla Powerwall), EV (Rivian), and weather (Open-Meteo) into one calm, data-forward interface with an automated 5-min decision loop.

Design thesis: **Rivian + Dieter Rams.** Precision instrument, warm surfaces, one hero numeral per view, six signal colors each meaning one thing.

## Repo structure

| Path | What it is |
|---|---|
| `prototype/` | Original React + Babel-Standalone design prototype. Tokens, IA, card copy, and flow viz validated here. Reference artifact — frozen. |
| `app/` | Production Next.js 16 app (App Router, TS, Tailwind v4, React 19). Hosts both the PWA and the `/api/*` surface. |
| `app/db/migrations/` | Canonical Postgres schema — first migration handwritten, subsequent generated by Drizzle Kit. |
| `app/src/db/schema.ts` | Drizzle typed schema, mirrors the SQL migrations. |
| `app/src/lib/decide.ts` | Pure decision engine. Unit-tested. No side effects. |
| `app/src/lib/db.ts` | Storage adapter — auto-switches between in-memory (dev) and Postgres (when `DATABASE_URL` is set). |
| `.github/workflows/cron-decide.yml` | External 5-min cron trigger. |

## Architecture

**Deployment:** Vercel Hobby (app) + Neon Hobby (Postgres) + GitHub Actions (cron trigger). Total cost $0/month.

**Why this stack:** portfolio-ready demo URL, $0/month at 2-user scale, and a clean multi-tenant upgrade path (add `household_id` FKs, Auth.js, Inngest/QStash fan-out). External cron via GitHub Actions avoids Vercel's tightening Hobby cron limits and keeps the project portable.

**Why not self-hosted on a Pi:** Pi wins on data fidelity (local Enphase Envoy + Powerwall Gateway APIs have no rate limits and give sub-second telemetry) but loses on portfolio visibility. Phase 3 (below) closes that gap.

## Phases

1. **Backend + PWA** (active) — Next.js API routes, Postgres, Zod validation, pure decision engine with unit tests, GitHub Actions cron, SWR-fed client.
2. **Integrations** — Enphase Enlighten v4 first (official, stable), Tesla Fleet API second, Rivian last (unofficial GraphQL, wrap with Smartcar fallback).
3. **Native iOS** — SwiftUI against the same `/api/*` endpoints. Widgets, Dynamic Island, Core Animation flow viz.
4. **Local agent (optional)** — tiny Node script on a Pi in the house that reads Enphase Envoy + Powerwall Gateway *local* APIs and POSTs to `/api/ingest` on the Vercel deployment. Unlocks sub-second telemetry and bypasses Tesla Fleet API quotas. Same pattern scales one-agent-per-household if Helios ever goes multi-tenant.

## Development

```bash
cd app
npm install
cp .env.local.example .env.local   # fill in DATABASE_URL + CRON_SECRET
npm run dev
```

Without `DATABASE_URL`, the app uses an in-memory store — fine for UI work. With it set, snapshots + actions persist to Postgres.

### Database

```bash
npm run db:push        # apply schema to DATABASE_URL (first-time setup)
npm run db:generate    # generate a new migration from schema.ts diffs
npm run db:studio      # browse tables in a local UI
```

### Tests

```bash
npm run test
```

Pure functions (currently `decide()`) get unit coverage. Route handlers are tested by hitting them via the running dev server.

## Deployment

1. Push the repo to GitHub.
2. Import into Vercel; `app/` as the root.
3. Set env vars in Vercel: `DATABASE_URL` (Neon pooled connection), `CRON_SECRET` (`openssl rand -hex 32`).
4. In GitHub repo settings → Secrets → Actions, add `HELIOS_BASE_URL` (your Vercel URL) and `HELIOS_CRON_TOKEN` (same value as `CRON_SECRET`).
5. The workflow at `.github/workflows/cron-decide.yml` takes over — 5-min ticks, logged in the Actions tab.

## Design constraints (from PRD v3)

- No drop shadows — hairline borders + surface tokens only
- One hero number per view
- Six signal colors max: solar=amber, battery=pine, vehicle=cyan, grid=blue, home=purple, alert=burnt-orange
- No red — "nothing in energy is an emergency"
- Tabular-nums everywhere, 8pt grid, 24px card radius
- All external API code in backend only, never in the PWA frontend

## API contract

| Endpoint | Method | Purpose |
|---|---|---|
| `/api/status` | GET | Instantaneous snapshot for the client |
| `/api/forecast` | GET | 24h hourly + 7d daily forecast |
| `/api/history` | GET | Time-bucketed historical snapshots |
| `/api/actions` | GET | Decision-engine log |
| `/api/rates` | GET | TOU schedule |
| `/api/config` | GET | Decision thresholds |
| `/api/reserve` | POST | Manual Powerwall reserve override (Zod-validated) |
| `/api/cron/decide` | GET | 5-min decision tick (bearer-authed) |

Response shapes live in [`app/src/lib/types.ts`](app/src/lib/types.ts); they mirror the validated prototype's `HELIOS_DATA` structure.
